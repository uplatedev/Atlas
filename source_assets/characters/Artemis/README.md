Op de laptop: haal de actuele `main` op in een schone checkout. Beide bestanden staan daarna rechtstreeks in `source_assets/characters/Artemis/`; er is geen Git LFS-download of apart assetpakket nodig. Controleer en bewaar eventuele lokale wijzigingen vóór het bijwerken van een bestaande checkout.
